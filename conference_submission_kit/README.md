# Conference Submission Kit (Pet Facial Expression Project)

This folder is a practical, execution-first package for converting the course project into a conference-ready paper.

## Who should use this
- Team members responsible for experiments, writing, reproducibility, and submission.

## What this kit contains
1. `01_contribution_reframing.md`
   - How to reframe the project from leaderboard engineering to publishable research contributions.
2. `02_gap_closure_execution_plan.md`
   - Step-by-step implementation plan for missing parts (ablations, statistics, robustness, external validation).
3. `03_paper_blueprint_and_draft_map.md`
   - What to write in each paper section and what evidence must be included.
4. `04_data_release_and_compliance.md`
   - What can/cannot be released, dataset/legal checklist, and recommended public benchmark strategy.
5. `05_reproducibility_package_spec.md`
   - Exact reproducibility artifacts and packaging standard.
6. `06_timeline_and_owners.md`
   - 8-week execution schedule with owner roles.
7. `07_submission_day_runbook.md`
   - Final checks before submission.
8. `templates/cover_letter_template.md`
   - Submission cover letter template.
9. `templates/reviewer_response_template.md`
   - Rebuttal template.
