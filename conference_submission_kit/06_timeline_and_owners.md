# 06. Timeline and Owners (8 Weeks)

Assign one primary owner and one backup for each line item.

## Week 1: Baseline lock + protocol
1. Baseline freeze (`v10`, `v15`) — Owner: [Name], Backup: [Name]
2. Experiment registry setup — Owner: [Name], Backup: [Name]
3. Seed/fold protocol lock — Owner: [Name], Backup: [Name]

Deliverables:
- Baseline records with commit/config hash.
- Shared experiment tracker.

## Week 2: Core ablations
1. Backbone ablation runs
2. Fusion ablation runs
3. Safety module toggles

Deliverables:
- Ablation raw metrics.
- Draft table skeleton.

## Week 3: Statistics + reliability
1. 5-seed repeated runs for core variants
2. Mean/std and significance tests
3. Re-check unstable outliers

Deliverables:
- Statistical appendix table.
- Reliability summary.

## Week 4: Error analysis + robustness
1. Slice-level performance analysis
2. Failure-case curation
3. Controlled perturbation tests

Deliverables:
- Error atlas figure.
- Robustness figure and caption.

## Week 5: External validity and compliance
1. External dataset transfer OR stress benchmark completion
2. Data/license verification
3. Dataset/model/repro card drafting

Deliverables:
- External validity table.
- Compliance statement draft.

## Week 6: Reproducibility packaging
1. Clean environment rerun
2. Artifact index completion
3. Script and command documentation

Deliverables:
- Reproducibility package v1.

## Week 7: Paper writing
1. Main text complete
2. Figures/tables finalized
3. Internal review (reviewer mode)

Deliverables:
- Submission draft v1.

## Week 8: Final polish + submission
1. Address internal comments
2. Final consistency checks
3. Upload paper + supplementary

Deliverables:
- Final submitted version.

## Progress tracking format
Use status tags for each task:
- `TODO`
- `IN_PROGRESS`
- `BLOCKED`
- `DONE`

Each DONE item must include evidence links (file paths).
