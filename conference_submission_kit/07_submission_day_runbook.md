# 07. Submission Day Runbook

## T-72h (3 days before)
1. Freeze manuscript text except typo fixes.
2. Freeze result tables and figure ids.
3. Regenerate all final numbers once.

## T-48h
1. Verify every claim has a table/figure reference.
2. Verify references/bib completeness.
3. Verify anonymity policy (if double-blind venue).

## T-24h
1. PDF format check (page limit, margins, fonts, embedded figures).
2. Supplementary completeness check.
3. Repro package archive check.

## T-12h
1. Run final spelling/grammar pass.
2. Verify author list and affiliations.
3. Verify conflict-of-interest entries in submission system.

## T-2h
1. Upload paper PDF.
2. Upload supplementary files.
3. Fill metadata fields exactly as in paper title/abstract.

## T-0h (final gate)
All boxes must be checked:
- [ ] Main claims linked to evidence.
- [ ] Numbers in abstract match result tables.
- [ ] Figure/table numbering consistent.
- [ ] License/compliance statement included.
- [ ] Reproducibility instructions included.
- [ ] Final PDF downloaded from submission portal and inspected.

## Post-submit
1. Tag repository commit used for submission.
2. Save final artifacts snapshot.
3. Start rebuttal preparation file immediately.
